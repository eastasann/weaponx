# コンセプト: weaponx

## 一言でいうと

Google ドライブに溜まった資料の関連を地図として描き、どれがどれにつながっているかを一目で分かるようにするツール。

## 誰のために

案件ごとにスライドとドキュメントが増え続ける職種（コンサル・営業・リサーチ職など）。まずは作者自身が日常的に使う。

## どんな課題を解決するか

Google ドライブに資料が増えるほど、資料どうしの関連性が見えなくなる。ファイル名とフォルダ階層だけでは「この提案書の元ネタはどれか」「これの最新版はどれか」が分からず、何を読まなければいけないのかが判断できない瞬間が多々ある。

ドライブの検索は個々のファイルを見つけるためのもので、資料のつながりは示さない。

## どんな体験を提供するか

資料どうしのつながりをグラフ（地図）として描く。「この提案書の元ネタはこれ」「これの最新版はこちら」が一目で分かり、ドライブ全体を俯瞰して眺められる状態にする。

## なぜ作るのか

自分が使いたい。自分（と同じ職種の人）の実害を消すことが目的なので、見た目より日常の使い心地と継続利用を優先する。

## 思いついているアイデア（箇条書きでOK）

- Google Drive API でファイル一覧とメタデータを取得する
- 関連の判定材料の候補: 資料内の相互リンク、タイトルの類似、更新時期の近さ、同一フォルダ、本文の内容類似
- 「最新版 / 旧版」の系列はまとめて1ノードに畳む
- 退避メモ: 当初の痛みは2つあった。「関連性が分からない」は地図で解けるが、「今何を読むべきか」は地図だけでは部分的にしか解けない。地図の上に「未読」「読む順」を重ねるかは Phase 1 で判断する
- Phase 1 で詰めたいこと: 対象範囲（マイドライブのみか、共有ドライブも含むか）、扱う資料の規模（数十件か数千件か）、関連の判定をどこまで自動でやるか
